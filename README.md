One original one-line dad joke: Dad put a clock on the dinner table so the family would always have time for seconds.

> Dad put a clock on the dinner table so we'd always have time for seconds.

## How it works

`main.py` (Python 3 standard library only) writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 140 characters of UTF-8 text, a single line.

```sh
python3 main.py
```
